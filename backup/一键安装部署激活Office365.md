Office Tool Plus是一款好用的Office部署软件，可以帮助我们快速部署Microsoft Office软件，本文将使用Office Tool Plus来演示如何安装激活Office 365。  
### 一、安装

1. 访问Office Tool Plus官网（https://otp.landian.vip/zh-cn/），下载最新版本的Office Tool Plus软件，建议下载包含框架的版本
![1](https://github.com/user-attachments/assets/15ef44c5-b8e0-486c-8c28-7b18e24ed0f6)

2. 下载好Office Tool Plus之后，用解压软件进行解压
![2](https://github.com/user-attachments/assets/78bde0c3-6aad-462b-be13-2166b8f91747)

3. 打开解压之后的文件夹，以管理员身份运行setup.bat
![3](https://github.com/user-attachments/assets/c536d52e-603a-410d-8757-57aaf013eec0)

4. 之后就会弹出CMD窗口，如下图所示，它正在安装所需的运行库组件，稍等片刻：
![4](https://github.com/user-attachments/assets/9546037c-7dbd-4096-8a9c-222e61d56b3d)

5. 运行库组件装上之后，会自动打开Office Tool Plus软件，然后点击「部署」按钮
![5](https://github.com/user-attachments/assets/14460c20-634a-4473-b976-db1a3570579d)

6. 在弹出的新窗口中，点击「添加产品」
![6](https://github.com/user-attachments/assets/e245f6e5-c10f-4209-9285-43b0f281e4bd)

7. 推荐选择「Microsoft 365」
![7](https://github.com/user-attachments/assets/d9a3e276-5ac6-419d-bc16-9877393d2dad)

8. 在应用程序里，选择你需要的组件，不需要的就取消勾选，这里我就安装三大组件：
![8](https://github.com/user-attachments/assets/7294f89a-7ba1-442e-b477-bd699e7b8080)

9. 点击「添加语言」
![9](https://github.com/user-attachments/assets/6c4b5a7a-5aca-4618-baee-b14ac1e5a5c6)

10. 默认添加的就是简体中文
![10](https://github.com/user-attachments/assets/1f675ed1-e797-4cbc-8407-fcb679fc6f72)

11. 来到右侧栏，选择你需要安装的位数、通道等，微软建议大家安装32位版本，因为32位版本支持的插件更多，当然64位的处理性能更强，你看情况选择吧，我这里就直接安装32位版了。另外，建议把下面的「创建桌面快捷方式」给勾选上，其他的就别动了
![11](https://github.com/user-attachments/assets/dbcabe1d-b921-4ea5-aa55-c540af0ecd1e)

12. 点击「开始部署」
![12](https://github.com/user-attachments/assets/4e8ec27c-f1ff-415f-89ff-a18fa077d5c1)

13. 紧接着会弹出一个提示框，选择「是」即可 
![13](https://github.com/user-attachments/assets/38ae3b1c-2dc0-4e23-8a61-814f37f3f115)

14. 正在准备部署...
![14](https://github.com/user-attachments/assets/2e59c33b-7c90-4ac1-800d-2ecdd1a09765)

15. 嗯，开始安装了
![15](https://github.com/user-attachments/assets/e829a9e3-c0ce-4aee-9565-4414443067f8)

16. 安装需要一点时间，别急... 
![16](https://github.com/user-attachments/assets/5771051d-853e-4280-bf93-6c41a14cc514)

17. 大概10余分钟后，就安装完成了，点击「关闭」
![17](https://github.com/user-attachments/assets/b736ff6e-1a0a-48f1-b3c8-771bb2595bc6)

18. 可以看到桌面已经有了Office软件的图标了，这个时候先别急着打开Office，我们直接进入激活步骤
![18](https://github.com/user-attachments/assets/27712d7b-4cf3-452d-85ae-299e1c95bc2b)

### 二、激活

1. 还是Office Tool Plus软件，点击左上角的返回按钮，返回到主页
![2 1](https://github.com/user-attachments/assets/82adfc81-8ef7-4101-9e4b-3e80a48538ed)

2. 点击「激活」按钮
![2 2](https://github.com/user-attachments/assets/84f644d7-bb1e-4399-a0c7-74c229b82f8b)

3. 来到激活界面，在许可证管理里，点击安装许可证右侧的下拉三角△符号，点击「清除所有许可证」
![2 3](https://github.com/user-attachments/assets/ef10e010-a5e0-4b7d-9eed-5bb479faa672)

4. 会弹出一个提示框，选择「是」
![2 4](https://github.com/user-attachments/assets/3312b869-6969-41b2-b0dd-ffee5a7d2f32)

5. 很快即可完成清除，右侧可以看到进度
![2 5](https://github.com/user-attachments/assets/1d3ed26f-1290-4a6d-8bd9-baa6fd8a56d4)

6. 在许可证管理里，选择「Office Mondo 2016 - 批量版」，点击安装许可证（别问为什么，这是唯一可以免费使用Office 365的途径）
![2 6](https://github.com/user-attachments/assets/1a449a9e-7be4-4802-bdb0-8554f67b6183)

7. 弹窗一个提示框，选择「是」
![2 7](https://github.com/user-attachments/assets/3107a88d-cd72-4cdc-9033-81b7534af031)

8. 稍等片刻，可以看到右侧栏有处理的进度
![2 8](https://github.com/user-attachments/assets/94a8055c-b261-45c2-8f24-a6f99992b3ba)

9. 许可证安装完成后，切换到「KMS管理」栏目。在「KMS主机」里填上KMS服务器，这里我填的是kms.****.beer，你也可以用这个，如果无法使用的，新的KMS服务器请到这里查找（https://www.coolhub.top/archives/14）。填完KMS主机后，点击「保存设置」按钮 
![2 9](https://github.com/user-attachments/assets/ec1aa3a5-562a-4365-bdeb-aef72a5f3941)

10. 在右侧栏，可以看到成功应用设置的提示
![2 10](https://github.com/user-attachments/assets/04abaf3f-d579-4037-b5ed-85661aa8e90c)

11. 最后，点击右上角的“激活”按钮
![2 11](https://github.com/user-attachments/assets/e04974d8-4639-43dc-81af-35130473df09)

12. 稍等片刻，即可看到激活成功的提示
![2 12](https://github.com/user-attachments/assets/c71195ab-ce56-46c0-87c9-65b4355c1b97)

### 三、后续的操作

1. 打开Office任意组件，会弹出许可协议提示框，选择接受 
![3 1](https://github.com/user-attachments/assets/d32999a7-c9d8-4d28-a8c7-576bf7aa0111)

2. 紧接着是隐私选项，点击关闭按钮 
![3 2](https://github.com/user-attachments/assets/c3699ba5-4f04-48b6-ac8d-e58b0e3a95e8)

3. 在Office的激活信息里可以看到，已经激活成功，虽然许可证类型写的是Mondo 2016，但实际上，功能和365无差别，你之后也可以在线更新的 
![3 3](https://github.com/user-attachments/assets/f931c0e9-bc3b-45dd-b918-86604e97f9d5)

4. PowerPoint的「设计灵感」功能可以使用（设计灵感是365专属功能）
![3 4](https://github.com/user-attachments/assets/2d83c436-ec74-452f-ad2e-37c78b651c65)

5. PowerPoint的「平滑」过渡也可以使用（平滑过渡也是365专属功能）
![3 5](https://github.com/user-attachments/assets/490949af-c0da-454d-81f4-14bec717a791)

### 四、补充说明
如果你想同时安装Project和Visio，那么可以在安装的步骤7后面，添加上相应的产品，但是需要注意，一定要添加正确的版本，否则会安装失败，正确的版本是：
- ProjectProXVolume
- VisioProXVolume
![4 1](https://github.com/user-attachments/assets/24ee8fbd-a3d9-4fc3-ba68-846f83db1cc1)
![4 2](https://github.com/user-attachments/assets/67df2f9c-348f-4a55-ada1-6ee3d4be251a)

Project和Visio两个组件不需要单独激活，执行了前面的激活步骤之后，Project和Visio也会一并被激活成功。
